- [ ] [roadmap.md](./roadmap.md) 填当前的路线图，没有就写「暂无」
- [ ] 和使用者确认：谁能把规划标为「已确认」

---

## 规则

1. **规划不是版本**：规划里的事项要进入版本，先进需求池（[backlog.md](../product/backlog.md)，SOP-00.5），再由 SOP-06 立项、SOP-01 写需求。不直接改版本文档
2. **每份材料标状态**：讨论稿 / 候选 / 已确认 / 已撤回。只有使用者明确确认的才能标「已确认」，写确认人、日期、原话；AI 的建议、推导写成「建议」，不写成结论
3. **日期是计划，不是承诺**：路线图上的时间写「计划」，和版本实际进度分开；版本实际进度以 `versions/` 为准，不在这里同步改
4. **撤回不删除**：方向变了，原材料标「已撤回」并写原因和替代它的材料，不改写原结论
5. **入口保持最新**：新增、撤回、替代材料都要同步下方「入口」表；材料多起来时按主题建子目录，入口只列当前有效的和最近撤回的
6. **对外汇报的材料冻结**：已经发出去的汇报、会议材料标「已汇报 {日期}，冻结」，后续修改另起新稿
