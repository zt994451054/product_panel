# maintainer/ — 模板维护区

> 本目录服务于**驱动面板模板本身的维护者**，不参与使用者的产品研发流程。
> 使用者拿到模板后可以整体删除本目录（同时删除 `.gitignore` 中的 `!/maintainer/` 一行）；
> 下游项目升级合并上游模板时，可保留 `validation/check.mjs` 用于检查合并后有无丢失 SOP、断链等问题。

| 目录 | 用途 |
|------|------|
| [validation/](./validation/README.md) | 面板优化效果的验证套件：静态检查、场景演练、历史回放、基线与对比报告 |

AI 在执行使用者的产品研发任务时**不读取**本目录。
