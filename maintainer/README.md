# maintainer/ — 模板维护区

> 本目录服务于**驱动面板模板本身的维护者**，不参与使用者的产品研发流程。
> 使用者拿到模板后可以整体删除本目录（同时删除 `.gitignore` 中的 `!/maintainer/` 一行）；
> 想继续用静态检查的，可以只保留 `validation/check.mjs`，改完面板规则后运行，检查 SOP 引用、断链、白名单吞文件等问题。

| 目录 | 用途 |
|------|------|
| [validation/](./validation/README.md) | 面板规则的验证套件：静态检查、场景演练、情景回放 |

AI 在执行使用者的产品研发任务时**不读取**本目录。
