## 用户流程

**时段预约**
1. 客户进入 `/web/slots`，按日期切换查看时段
2. 点击可预约时段 → 进入 `/web/booking/confirm`，点「确认预约」
   → 成功：进入成功页
   → 时段刚被约满（409）：提示「该时段已被预约」，返回列表并刷新
   → 超出上限（422）：提示「最多同时持有 3 个未开始的预约」
3. 未登录访问 `/web/booking/confirm` → 跳转登录页，登录后回到确认页

**时段管理**
1. 管理员进入 `/web/admin/slots`，点「批量创建」填写日期范围与时间段
   → 与已有时段重叠的跳过，提示「已创建 N 个，跳过 M 个」
2. 点「关闭」→ 确认框 → 确认后客户侧不再显示；已有预约的时段关闭按钮置灰并提示「已有预约，不能关闭」

## 补充交互逻辑

- 时段卡片：可预约为主色描边，已约满为灰底并显示「已约满」，已过去为置灰不可点击。
- 确认预约按钮点击后进入 loading，禁止重复提交；失败时在按钮上方显示错误文案，保留已选时段。
- 批量创建弹窗提交后，在列表顶部用提示条展示「已生成 N 个，跳过 M 个重叠时段」。
