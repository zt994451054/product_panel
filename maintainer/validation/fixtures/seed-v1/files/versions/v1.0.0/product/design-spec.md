## 原型增量

### 本版本原型变更

- 新增 `/web/slots` 时段列表页（按日期切换，时段卡片三种状态：可预约 / 已约满 / 已过去）
- 新增 `/web/booking/confirm` 预约确认页与成功页
- 新增 `/web/admin/slots` 时段管理页（批量创建弹窗、关闭确认）

### 原型页面 ↔ 需求模块映射

| 原型路由 | 所属终端 | 对应需求模块 | 还原优先级 |
|---------|---------|------------|-----------|
| `/web/slots` | Web | 时段预约 | 高保真 |
| `/web/booking/confirm` | Web | 时段预约 | 高保真 |
| `/web/admin/slots` | Web | 时段管理 | 参考还原 |

## 补充交互逻辑

- 时段卡片：可预约为主色描边，已约满为灰底并显示「已约满」，已过去为置灰不可点击。
- 确认预约按钮点击后进入 loading，禁止重复提交；失败时在按钮上方显示错误文案，保留已选时段。
- 批量创建弹窗提交后，在列表顶部用提示条展示「已生成 N 个，跳过 M 个重叠时段」。
