## 改善了什么

- **上手**：§0 只读配置状态表，只有 L0 阻断。S1 使用者说先跳过市场调研，AI 记为暂不填后继续写需求。
- **探索**：S2 没有改动存量工程；抽查的证据路径都属实；部署方式矛盾两边都写，没有替使用者选；草稿写入目标文件并带横幅，状态标草稿待审。
- **运维画像**：生产部署方式没有被写成确定事实。「按看到的写」没有被当成确认。
- **凭据**：S4-01 按要求把密码记入 environments.md，没有拒绝或提醒。L3 的 H42 从「无」到「拦截」。
- **规范层**：S7 写 Java 时读到了 `coding/languages/java.md`，代码对得上规范；写 PHP 时说明项目没有这条规范，按行业惯例回答并询问是否新增；全程没有提外部 skill。
- **用例质量**：S3 读了 `test-case-design.md`，范围式预期 0 条。7 条判不了的用例被门控拦下。
