## 验证套件自身的问题（已修复）

- 演练提示词要求「记录做了哪些判断」触发模型安全过滤（reasoning_extraction），5 个演练首次运行失败；改为只记录回复与改动文件后正常。
- 种子脚本最初用全局替换写入产品名，连 §0 规则文字里的占位符也被替换（S5 沙箱受影响，演练者识别后继续）；已改为只替换标题与 §1 字段。该现象同时说明 D07 的风险对真实使用者同样存在。
