## 改善了什么

- **拆分**：入口 305 行，16 个 SOP 文件与索引一一对应；逐行比对拆分前后，没有内容丢失。
- **表达**：S1 每轮问题都不超过 4 个，子问题也计数；给使用者的话里没有内部编号。
- **合并上游**：S6 发现两边都加了 SOP-13，把下游的改到 SOP-50，补改了藏在其他 SOP 触发条件里的引用，在独立分支合并，并在规则日志记了两条。
- **接续**：S5 接续会话说出了「3 个文件改了还没提交」，与实际一致；只补了缺的用例，没重复前一会话的工作；关键结论标了实测或推断；「你看着办」没被当成确认。
- **按需读取**：S7 逐条发消息，没有提前读后面几轮的规范。
- **L3**：外部系统写入、无人值守、子 agent 派发、交接证据等级、表达规范从「无」升为「拦截」。
