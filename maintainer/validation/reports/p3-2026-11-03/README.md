## 改善了什么

- **范围**：S3 中途「顺手加导出 Excel」被识别为范围扩大，使用者说「先登记」后没有改需求和设计；S8 新增取消功能在使用者确认后才改需求，版本范围表写了来源。
- **决策**：S3 的「前两条按建议」只记了前两条；S8 的「你看着办」「先不定」「自由发挥」「先不管那些了」都没被记成决定。旧决定被新决定替代时留了痕迹，重新设计时核对了已有决定。
- **长期不答复**：S8 第二次没得到答复后，AI 不再重复长清单，给出逐条决定、移出本版本、挂起三条出路，没替使用者选。
- **测试可信**：
  - S3 有执行就绪表和测试数据台账，进入测试前核对了被测构建。
  - 浏览器授权弹框记为人工干预并做了判定。
  - 依赖未决问题的用例记阻塞。
  - 没有另建统计表。
- **你决定**：S4 的「你决定」没有被当成决定，第 3 轮变更标了范围影响。
- **L3**：范围、假设、决策、执行就绪、人工干预、统计单一来源、缺陷回写、测试数据从「部分」升为「拦截」；测试数据操作口径的矛盾已消除。
