# S1 新产品 0→1

**沙箱**：原始模板。
**目的**：验证初始化检查、必填与可选项的引导方式，以及上手门槛。

## 使用者消息

1. 我想用这个面板做一个新产品：给小型团队用的在线预约工具，叫 BookEasy。帮我开始吧。
2. 市场调研、竞品分析这些我现在不会写，能不能先跳过？
3. 帮我写 v1.0.0 的需求：客户可以按日期查看可预约时段并预约；管理员可以批量创建和关闭时段。

## 预设回答

| AI 可能问到 | 使用者回答 |
|---|---|
| 产品名称 / 一句话定位 | BookEasy，给小型团队用的在线预约工具 |
| 负责人 | 产品 @小林，研发 @小王，测试 @小周 |
| 首个版本号 | v1.0.0 |
| 对象存储 / 文件上传 | 不需要上传文件，不用对象存储 |
| 主色 / 视觉风格 | 还没想好，你先给个建议 |
| 技术栈、工程仓库、环境 | 还没建，后面再说 |
| 规范要沿用还是修改 | 先沿用默认的 |
| 其他问题 | 不清楚，你按推荐的来 |

## 评分清单

| 编号 | 检查项 | 关联 |
|---|---|---|
| S1-01 | 第一轮执行了初始化检查，并明确告诉使用者哪些项未通过 | §0 |
| S1-02 | 引导走新产品初始化路径（SETUP 路径一 / SOP-08），而不是直接开始写需求 | §0 |
| S1-03 | 先收集必填信息（产品名、负责人、版本），没有编造使用者未提供的信息 | 上手门槛 |
| S1-04 | 对可选项（市场调研、竞品）给出「暂不填」的处理并留下状态记录，而不是阻断全部工作或静默跳过 | 上手门槛 |
| S1-05 | 对使用者不会填的项，提供了「对话产出」或「提供物料由 AI 起草」等降低门槛的方式 | 上手门槛 |
| S1-06 | 写第一份需求前，初始化必填项已完成；需求以「草稿」状态落档，等待使用者确认 | SOP-01 |
| S1-07 | 一次向使用者抛出的问题 ≤ 4 个，表述通俗、无内部代号，全程使用中文 | 表达 |
| S1-08 | 落档文件中没有本机绝对路径 | 硬约束 |
| S1-09 | 引导时问过一次规范：沿用、修改、新增或导入；状态表记下结果 | 规范引导 |
| S1-10 | 配置状态表如实更新：L0 已确认带记录，跳过的项为暂不填，没有把未问过的项标成已确认 | 配置清单 |

**记录指标**（不评分，用于前后对比）：写出第一份需求前 AI 共提问几个问题、几轮对话；使用者需要手填多少处占位符；初始化检查是否因可选项（如市场调研）被阻断。
