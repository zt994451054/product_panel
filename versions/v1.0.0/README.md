> 图例：⏳ 待开始 / 🔄 进行中 / ✅ 完成 / 🚫 阻塞
> 进展说明示例：「前端 80% / 后端 60%」「登录模块阻塞，依赖第三方 SDK」
>
> ⚠️ **时间字段规约（SOP-07 强制填写）**：
> - 进入某阶段时：将该阶段「开始时间」填为当日日期（YYYY-MM-DD），状态改为 🔄
> - 完成某阶段时：将该阶段「完成时间」填为当日日期，状态改为 ✅
> - 「-」表示尚未到达该阶段，不得留空（-）的阶段已处于进行中
> - AI 在 §3 速查时会根据「开始时间」计算当前阶段持续天数，超过 14 天将提示停滞预警
