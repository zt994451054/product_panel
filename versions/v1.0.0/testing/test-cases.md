## 说明

- 新增用例时须同步更新：①顶部「用例总览」表新增一行；②在详情区添加对应章节；两处的类型、优先级保持一致
- 用例执行结果更新时，须同步以下三处：
  1. 本条用例详情：填写「实际结果」，更新「执行状态」
  2. 顶部「用例总览」表：更新对应行的执行状态
  3. 顶部「用例统计」表：更新对应计数
- 执行失败时状态改为 ❌，在「关联缺陷」字段填写缺陷编号，并在 defects.md 创建缺陷记录
- 变更导致的用例调整通过 CHANGES.md 统一追踪
→ 见 [CHANGES.md](../CHANGES.md)
