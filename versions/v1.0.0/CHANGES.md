# v1.0.0 变更记录

> 规约：任何需求调整、设计变更、方案修改，必须先登记变更，再修改对应文档。
> 禁止直接修改文档而不留变更记录。

变更的登记和处理进度不写在本文档里。每次变更先用 `node tools/panel.mjs change open` 登记，拿到编号，再改文档；每改完一份运行 `change handle`；全部处理完、使用者确认后运行 `change close`。用 `change list --version {版本}` 查看，`status` 会列出每条没完结的变更还差哪几份文档。

本文档只写叙述：改了什么细节、为什么、还没处理的由谁在什么时候之前处理。
