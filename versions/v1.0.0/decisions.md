# v1.0.0 决策记录

> 本版本内使用者做出的决定：需求取舍、待确认问题的答复、暂定值、范围扩大、不测的项等。跨版本的技术选型仍写 `foundation/tech-arch/decisions/`（ADR）。
> 重新设计、改方案、改用例前，先查本表，不违背仍有效的决定；要推翻就新增一条并在旧条目填「被替代」。

**记录规则**（[AGENTS.md](../../AGENTS.md) §5.1）：
- 只记使用者明确说出的决定，「使用者原话」照录，不改写、不扩大
- 未答复、「你看着办」「你按规范来」不是决定，不记在这里；问题留在原处继续待确认
- 「按建议」「按推荐的来」只对上一条消息里逐条列出的建议生效：每条建议记一行，原话写「按建议（指：……）」
- `requirements.md`「待确认问题」有了答复，就在这里记一条，并在原问题后注明决策编号
- 需求、范围、验收标准类的决定由 `versions/CURRENT.md` 登记的产品负责人做；对话者身份无法核实时，「决定人」写其自报姓名，未报写「当前使用者」，并在汇报中提醒负责人复核
- 用例和缺陷的豁免记在 `testing/test-report.md`「豁免登记」，阶段签收记在版本 README「签收」列，不在这里重复；其余决定（含无人值守的预授权、生产验收中的遗留决定）都记在这里
