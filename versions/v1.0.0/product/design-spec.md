## 全局交互规范

> 对本版本所有页面生效的通用行为，局部页面有特殊要求时在页面详情中覆盖

| 场景 | 交互行为 |
|------|---------|
| 页面加载中 | <!-- 如：展示骨架屏，不展示空内容 --> |
| 接口请求中 | <!-- 如：按钮置灰 + loading 图标，防止重复提交 --> |
| 网络错误 | <!-- 如：Toast 提示「网络异常，请稍后重试」，不清除已填内容 --> |
| 无权限访问 | <!-- 如：跳转 403 页面，展示「暂无权限」提示 --> |
| 空状态 | <!-- 如：展示空状态插图 + 引导文案，不展示空列表 --> |
| 表单校验时机 | <!-- 如：失焦时校验单个字段，提交时校验全部字段 --> |
| 操作成功反馈 | <!-- 如：Toast 提示成功文案，持续 2 秒后自动消失 --> |
| 操作失败反馈 | <!-- 如：Toast 提示错误原因，持续 3 秒后自动消失 --> |
