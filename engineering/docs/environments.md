# 多环境配置说明

## 环境概览

| 环境 | 域名/地址 | 用途 | 部署方式 |
|------|---------|------|---------|
| dev | localhost | 本地开发 | 手动启动 |
| staging | <!-- 如：https://staging.example.com --> | 测试/验收 | CI 自动部署 |
| prod | <!-- 如：https://example.com --> | 生产环境 | 手动发布 |

## 环境差异对照

| 配置项 | dev | staging | prod |
|--------|-----|---------|------|
| API Base URL | http://localhost:8080 | <!-- --> | <!-- --> |
| 数据库 | 本地 Docker | <!-- --> | <!-- --> |
| Redis | 本地 Docker | <!-- --> | <!-- --> |
| 短信发送 | Mock（不实际发送）| 沙箱/真实 | 真实 |
| 日志级别 | debug | info | warn |
| 错误详情 | 完整展示 | 部分展示 | 不展示 |

## 环境变量说明

> 以下列出关键环境变量的说明（不含实际值，实际值在各环境的 .env 文件中）
> 敏感配置不可提交到 git，通过配置中心或密钥管理系统注入

| 变量名 | 说明 | 示例值（非生产）| 是否敏感 |
|--------|------|--------------|---------|
| `DATABASE_URL` | 数据库连接字符串 | `mysql://root:pass@localhost:3306/db` | 是 |
| `REDIS_URL` | Redis 连接地址 | `redis://localhost:6379` | 否 |
| `JWT_SECRET` | JWT 签名密钥 | 随机字符串 | 是 |
| <!-- 如：SMS_API_KEY --> | <!-- 短信服务 API 密钥 --> | <!-- --> | 是 |

## 新增环境变量流程

1. 在 `tech-solution.md` 的「配置变更需求」节登记
2. 更新本文件环境变量说明表
3. 更新各工程仓库的 `.env.example` 文件
4. 通知相关人员在各环境配置中心更新
